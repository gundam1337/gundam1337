## My Story

I did not start as a software engineer.

Before writing production backend services, designing authentication flows, and integrating complex APIs, I was a **mathematics teacher**.

Teaching math trained me to do something very important in engineering:

> take complex problems, break them into small pieces, explain them clearly, and solve them step by step.

That mindset followed me into software engineering.

I studied at **1337 Coding School**, where I built a strong foundation in low-level systems, problem solving, C/C++, algorithms, and project-based learning.

Today, I work as a **Full-Stack Engineer with a backend focus**, building real-world systems with **NestJS, Spring Boot, Node.js, PostgreSQL, OracleDB, Redis, Next.js, React, and TypeScript**.

I enjoy the hard parts of engineering: authentication, onboarding flows, database design, API integrations, background jobs, monitoring, debugging, and clean architecture.
